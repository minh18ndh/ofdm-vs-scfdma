\subsection{Simulation Objectives}

The purpose of this chapter is to evaluate and compare the performance of
OFDM and SC-FDMA through numerical simulation. Two key metrics are
considered:

\begin{itemize}
    \item Bit Error Rate (BER)
    \item Peak-to-Average Power Ratio (PAPR)
\end{itemize}

The simulations are implemented in MATLAB using equivalent system
parameters for both transmission schemes.

%============================================================%
\subsection{System Model}

For a fair comparison, both systems use identical modulation order,
channel conditions, and noise levels. The only structural difference is
that SC-FDMA includes a DFT precoding stage before subcarrier mapping.

The transmitter models are summarized below:

\begin{center}
OFDM: Bits $\rightarrow$ QAM $\rightarrow$ IFFT $\rightarrow$ CP
\end{center}

\begin{center}
SC-FDMA: Bits $\rightarrow$ QAM $\rightarrow$ DFT $\rightarrow$
IFFT $\rightarrow$ CP
\end{center}

At the receiver, inverse operations are performed to recover the
transmitted bits.

\subsection{Bit Error Rate Comparison}

For each Signal-to-Noise Ratio (SNR) value, random bits are generated,
transmitted, detected, and compared with the original bit stream.

BER is computed as:

\begin{equation}
\mathrm{BER}
=
\frac{N_e}{N_t}
\end{equation}

where:

\begin{itemize}
    \item $N_e$ is the number of bit errors
    \item $N_t$ is the total number of transmitted bits
\end{itemize}

Under AWGN conditions, OFDM and SC-FDMA generally provide similar BER
performance when the same modulation and coding assumptions are used.

\subsection{Peak-to-Average Power Ratio Comparison}

PAPR is calculated for each transmitted frame using:

\begin{equation}
\mathrm{PAPR}
=
\frac{\max |x[n]|^2}{E\{|x[n]|^2\}}
\end{equation}

OFDM signals are formed by summing many subcarriers. When these
subcarriers align constructively, high peaks occur. Therefore, OFDM
typically exhibits larger PAPR than SC-FDMA.

\subsection{Discussion of Results}

Based on expected communication theory results:

\begin{itemize}
    \item OFDM offers simple multicarrier transmission and excellent
    robustness against frequency-selective channels.

    \item SC-FDMA achieves similar BER performance under equal
    conditions.

    \item SC-FDMA provides lower PAPR, improving transmitter power
    amplifier efficiency.

    \item Lower PAPR makes SC-FDMA highly suitable for mobile uplink
    systems where battery life is important.
\end{itemize}

Therefore, the choice between OFDM and SC-FDMA depends on whether system
priority is receiver simplicity, transmitter efficiency, or standard
requirements.
