\subsection*{Source Code Repository}

The complete source code used in this report is publicly available on
GitHub. The repository contains:

\begin{itemize}
    \item MATLAB simulation source code
    \item BER and PAPR evaluation scripts
    \item LaTeX source files for the report
    \item Generated simulation figures and plots
\end{itemize}

The repository can be accessed at:

\vspace{0.3cm}

\noindent
\url{https://github.com/minh18ndh/ofdm-vs-scfdma}

\vspace{0.3cm}

\vspace{0.5cm}

The repository was created to improve reproducibility and allow future
extensions of the simulation framework, including:

\begin{itemize}
    \item Localized and Interleaved SC-FDMA
    \item Higher-order modulation schemes
    \item Channel estimation techniques
    \item Nonlinear power amplifier modeling
    \item LTE and 5G NR parameter configurations
\end{itemize}
